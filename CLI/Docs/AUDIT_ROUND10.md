## 修订

1. iOS X/Z 剖面的反向默认投影此前只改变遍历顺序，却仍使用平面后方范围。现在正向为 `[plane-depth+1, plane]`，反向为 `[plane, plane+depth-1]`；显式导出范围继续优先。
2. iOS biome / tickingAreas / slime 属性采样改为实际 fixedX / fixedZ 平面，不再用投影范围前沿。特别是开启未生成纹理时，同一区块内不同 X/Z 位置的生物群系不会被强行改读区块边缘。Windows 既有属性模式已经读取指定平面。
3. iOS 渲染与自动点选共用 `MapCoordinate.projectionRange`：普通模式 128 格，矿物 129 格；未生成层开启时为所在区块的 16 格；属性模式自动点选限于当前平面。此前普通模式多选一格，纹理模式仍搜索旧的 129 格范围。手动 ±128 格仍保留；无命中时落到实际投影前沿。异步读取前捕获模式和自动范围，避免读取完成时改用另一模式。
4. 共享范围计算使用溢出检测，整数极值处截断；所在区块使用负坐标 floor 规则。此保护仅覆盖该范围函数，不表示所有地图输入、跨度和栅格算术都已处理极值。
