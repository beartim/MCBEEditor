# kill 维度与范围目标

按本次需求新增 `kill 维度 x1 y1 z1 x2 y2 z2 0或1`，旧目标格式继续可用。
沿用实体查询的有限浮点坐标、维度名称／Int32 ID、闭合长方体和反向角点规则；按实际 Pos 和解析后的维度选择普通实体与玩家，不涉及方块实体。
普通实体批量删除；选中的非创造模式玩家无论开关为何值均清零现有生命值；创造模式玩家仅在开关为 1 时清零。
Swift 与 C# 使用现有目标类型增加范围目标，复用玩家位置读取与实体扫描／批量删除，不改变其他命令的输入格式。范围扫描按存储记录保留实体，避免相同 UniqueID 导致漏删。
另一种实现是独立增加范围 kill 命令请求，但会重复原有生命值与删除流程，因此采用扩展目标类型。
保留版本号与 iOS 13 兼容性，不增加产品依赖。同步 GUI、CLI、固定 ReadMe 和命令清单，并提供行为回归。
