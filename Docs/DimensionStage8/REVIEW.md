审查范围：原始源码基线至第 8 轮功能实现。审查为只读；三项复现均使用独立内存数据库，没有修改用户样例。根据审查结果完成一次修正，并增加 Swift/C# 对应回归测试。

| 级别 | 发现 | 修正与验证 |
| --- | --- | --- |
| Critical | `VILLAGE_overworld_custom_uuid_RAID` 被原版 `overworld` 前缀抢先匹配，清空/删除主世界可能误删自定义维度的村庄 | 原版回退名称与登记名称统一匹配，选择最长完整名称；同长度对应多个 ID 时拒绝。覆盖三个原版前缀、empty/purge、保留其它维度与删除目标。 |
| Important | 只有未知标签 `0x7f` 区块的未登记维度未被发现，无法清理或阻止重复 ID | 使用原始区块键形状提取坐标与完整 Int32 ID，不依赖区块标签枚举；排除维度根、已知全局键和元数据前缀。覆盖 9–11/13–15 字节键、碰撞 ID、Int32 两端、查询无写入、重复 add、empty、purge。 |

三项问题在原环境的两端专项测试中先失败后通过；执行环境恢复后，同一生产逻辑与完整回归测试已恢复并重新验证。新回归汇总在 `DimensionSafetyRegressionTests`。

审查未作结论的事项按既有设计处理：Apple 平台编译与运行留待具备 Xcode/SDK 的环境；玩家迁移使用已说明的固定坐标，不新增地形探测；命令文件预检保证开始前无写入，运行时失败仍按已有逐条执行/导出规则处理；未提供 schema 的私有元数据不扩展猜测性删除。

测试控制键 `existing_global` 长度恰好为 15 字节，与合法原始区块键形状重叠，改为 `existing_global_control`。这是合成测试数据调整，没有增加忽略真实二进制键的启发式规则。
