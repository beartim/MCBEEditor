# fill / setblock 方块实体参数

1. 四端共用解析器要求最后一个参数为 `preserve`、`empty` 或完整 MCBE-SNBT 标签列表；原有 1…255 个 storage 配对保持不变。
2. SNBT 根 x/y/z 可省略；输入时按不区分大小写的名称忽略，写入时根据命令的实际目标位置添加唯一的小写 Int 坐标。允许任意 id，不检查其与方块类型的对应关系。fill 将模板复制到每个目标位置，并分别写入实际坐标；其余标签的值、相对顺序和类型保留。
3. preserve 不解析或改写已有方块实体。empty 删除范围内全部匹配记录。SNBT 删除目标位置旧记录（包括重复记录），逐位置写入一份模板，保留其他实体与不可定位记录。方块、实体及缺失区块元数据统一提交一次 WriteBatch；全部校验及编码在提交前完成。

   定位只接受唯一的整数根 x/y/z 和精确 Int32 坐标，不使用辅助 Pos，不对浮点或越界 Long 取整/钳制。追加到旧单根 VarInt 数据时归一化为 little-endian 连续 NBT 流，以保证追加结果可读。
4. 先验证旧实现拒绝省略根坐标的回归，再覆盖三种模式、空 List、任意 id、反向和跨区块范围、被忽略的根坐标及类型、嵌套坐标保留、实体损坏以及拒绝后的存档一致性。
5. 同步四端帮助、命令清单、四份静态 Commands/ReadMe.txt 和写入常量、现有示例与回归；运行 Swift/C# 核心、CLI 及固定 ReadMe 检查，交付完整源码包。

原版与自定义维度均适用。输入根坐标不再参与定位或限制目标范围；既有方块实体的安全定位规则保持不变。
